# Assumptions and decisions

1. **Seats are counted, not stored.** Taken seats are the holds that are CONFIRMED, or HELD with time left, counted at read time. An expired hold stops counting the moment its time passes, so no background job is needed. A row may still say HELD in the table after it expired; every query treats it as EXPIRED.
2. **How the seat limit is kept.** Applying runs one transaction that locks the class row with `select ... for update`, counts the taken seats and inserts the hold. Every request for that class waits at the database in turn, so two requests can never both take the last seat. Paying takes the same class lock, so a payment in the very second a hold ends cannot race with a new applicant. The lock lives in PostgreSQL, not in the API process, so the same is true for two backend processes on one database. All time checks use the database clock.
3. **One hold per class per student.** A student can hold seats in different classes at once, because the rule speaks of one class. A partial unique index backs this up in the database.
4. **Applying again is allowed** after a hold EXPIRED or was CANCELLED.
5. **A confirmed admission cannot be cancelled** through this API. Cancel on it returns 409 HOLD_ALREADY_CONFIRMED.
6. **Repeats are safe.** A second confirm by the owner returns 200. A second cancel returns 204. Cancel after expiry returns 409 HOLD_EXPIRED.
7. **Status codes.** 400 bad input or bad header, 403 another student's hold, 404 unknown class or hold, 409 for rule conflicts (full, already applied, expired, cancelled, confirmed), 503 when the database stays busy. Checks run in the order 404, then 403, then status.
8. **X-Student-Id** must be exactly 17 ASCII digits after trimming spaces, as the assignment's example shows. Anything else is 400. The frontend turns Bangla digits into ASCII before sending.
9. **Class names** are not unique. Spaces at the ends are trimmed. A name may not be empty, longer than 100 characters, or contain control characters. `totalSeats` is a whole number from 1 to 100000.
10. **GET /holds/{holdId} needs no header**, as the assignment shows none, so it never returns the student number.
11. **expiresAt is in whole seconds** (`2026-11-01T04:10:00Z`) to match the assignment's example, so a hold can be up to one second shorter than the setting.
12. **Classes are edited only through new office endpoints.** The original API has no endpoint for it, so editing, closing and changing seats live under `/office/classes`. Seats never go below the seats in use, checked under the class lock. Classes are never deleted, so no history is lost.
13. **No seed data.** A fresh database is empty.
14. **No authentication by default**, as the assignment requires. Anyone who knows a birth registration number can act as that student, and anyone can create a class. `SIGN_IN_REQUIRED=true` adds guardian sign-in by mobile code and staff login; `RATE_LIMITS_ENABLED=true` adds rate limits. Both are off by default so the original endpoints answer exactly as specified. Office features on new endpoints always need a staff login.
15. **Dapper with hand-written SQL** is the ORM. Every seat rule is one SQL statement, so writing the SQL directly is the clearest way to show and check it, and there is no migration tooling to get wrong.
16. **The UI remembers the number on the device** (localStorage), so a guardian who closes the browser comes back to the running hold. The "নম্বর বদলান" (Change number) button clears it.
17. **Payment is a sandbox.** For a class with no fee, "ভর্তি ফি দিন" confirms through the original endpoint. For a class with a fee, it goes through a sandbox gateway with a hosted page, an HMAC-signed callback and an idempotency key. No money moves, and no bank name or transaction number that could pass for a real one is shown.
18. **Language and time.** The UI starts in Bangla with an English switch. The API sends UTC; the screen shows local time.
19. **Busy database.** If waiting for the class lock passes 20 seconds twice in a row, the answer is 503 SERVER_BUSY with Retry-After. This should not happen in normal use.
20. **Admission sessions only bind classes added to them.** A class made through the original `POST /classes` has no session and is always open, so the original contract is unchanged. A class inside a session takes applications only inside its window, checked under the class lock on the database clock.
21. **The age rule is "completed years on the cut-off date".** Someone born on 29 February turns a year older on 1 March in other years. The 2027 non-government school policy, as reported by the press on 11 and 12 November 2026, asks for 6 to under 7 years on 1 January for Class 1; the office sets it per class as minimum 6, maximum 6, cut-off 1 January 2027. The official circular could not be reached, so this is not hard-coded.
22. **Mobile numbers are 01 followed by 3 to 9 and eight more digits** (013 to 019). Prefixes come from press reports of BTRC allocations; the BTRC numbering plan PDF could not be read here. Since number portability, the prefix does not identify the operator, so no operator is checked.
23. **Documents are stored in the database**, up to 300 KB for a photo and 1 MB for a certificate, with their type read from the first bytes. The database survives restarts on hosts whose disk is wiped, and nothing is ever served from a public path.
24. **The waiting list comes first.** While anyone is waiting for a class, a newcomer cannot take a freed seat there; the seat is offered to the next person in line as a new hold with its own timer.
25. **A payment that arrives after the hold ran out is marked LATE** and does not take the seat, which may already belong to someone else. The refund is shown as due; nothing is paid back by the app.
26. **A rejection frees the seat.** The hold becomes CANCELLED, so the original endpoints still only ever show the four original statuses; the decision and the reason live in the review record.
27. **The slip's PDF is the browser's "Save as PDF".** The slip page is print ready. A server-made PDF would need a large font-shaping library to set Bangla names correctly.
28. **Lottery admission and reading the certificate with OCR are not built.** The lottery needs the official circular's procedure, which could not be reached; OCR of a 17 digit number could not be done with a small, explainable component and an honest accuracy figure.
